Загрузи команду `full-task` через инструмент `skill` и выполни её полностью, с одним отличием.

Каждый запуск субагента из `full-task` (ревьюеры §6/§8, исследователи репозитория, параллельные исполнители)
делай не встроенным инструментом `agent`, а инструментом harness:
`mcp__harness__worker_run` (или `mcp__harness__agent` с теми же аргументами, что у встроенного `agent`):
- `profile` / `subagent_type` — имя агента из `full-task` (например `java-reviewer`, `repository-explorer`);
- `model` — модель из таблицы §8 (id или имя грейда: `review`, `fast`, …);
- `spec` / `prompt` — то же задание, что ты передал бы встроенному агенту.

Параллельные субагенты — по одному вызову `worker_run` на шаг, каждый с `run_in_background: true`: они работают
одновременно, итоги придут сообщениями. Несколько вызовов в одном шаге GigaCode может отклонить («tool_call bridge
refused … name») — тогда повтори их по одному. Всё остальное в `full-task` без изменений.
